# P## SQLite Storage Module

The SQLite storage module is responsible for storing
chronological execution states generated by PyChronicle.

Stored information includes:
- Execution position
- Timestamp
- Line number
- Variable name
- Serialized variable value

The module supports:
- State insertion
- Batch insertion
- Historical state retrieval
- Variable history
- Delta-based storage
- Value serialization
- SQLite error handlingroject-PyChronicle-AST-Powered-Time-Travel-Debugger
